# Contributing

Thank you for helping improve the project.

1. Discuss substantial UI, capture, file-format, privacy, or permission changes before implementation.
2. Keep changes focused and add regression coverage for observable behavior.
3. Run `swift test` with a complete Xcode installation. Also run `Scripts/run-core-tests.sh` and `Scripts/build-app.sh release` when changing capture, rendering, packaging, or UI code.
4. Do not commit screenshots containing private information, credentials, signing identities, provisioning profiles, build products, or copied third-party assets.
5. Confirm that contributed code and assets may be distributed under the MIT License, and document any third-party material and its license.

Bug reports should include the macOS version, Mac model/display arrangement when relevant, reproduction steps, and expected behavior. Redact personal data from screenshots and logs.
