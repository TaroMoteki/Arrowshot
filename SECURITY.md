# Security Policy

## Supported versions

Security fixes are provided for the latest published release and the latest source revision.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature if it is enabled for this repository. Do not include sensitive screenshots, credentials, or personal information in a public issue.

Maintainers should acknowledge a report as soon as practical, reproduce it in a private environment, and publish a coordinated fix before disclosing technical details.

## Scope

Security-sensitive areas include Screen Recording permission, capture selection, imported image parsing, file export, clipboard access, and future signing or update mechanisms.
